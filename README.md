# 12층 화재경보 — Fire Alarm Popup (version 4)

> ⚠️ 이 결과물은 **목업(mock-up)** 이다. 실제 센서·관리실·소방 연동은 없고,
> 흐름과 화면을 보여주기 위한 프로토타입이다. 데이터/타이밍은 시연용 더미다.

월패드 화재경보 팝업. 상황 정보를 수집(로딩)하다가 조건이 충족되면 전체 화면(메인 화면)으로
자동 전환된다. 전체 흐름을 유튜브식 타임라인으로 스크럽/재생할 수 있다.

## 파일
- fire-alarm-popup.html  — 마크업 + 스타일 (Tweaks 패널 포함)
- popup.js               — 동작 전부 (타임라인 엔진, 시나리오, 권한, Tweaks 상태)
- README.md              — 이 문서

## 실행
fire-alarm-popup.html 을 브라우저로 열거나 정적 서버로 서빙:
    npx serve .

## 4개 확인 항목의 의미
팝업 수집 단계에 뜨는 체크리스트의 각 항목이 실제로 뜻하는 것:

1. **감지기 신호 확인**
   화재경보기(감지기)가 보낸 신호에 월패드가 접근·수신하는 단계.
   "경보기 신호를 월패드가 잡았다"를 보여준다.

2. **발생 위치 특정**
   그 화재경보기가 해당 층 안에서 **어느 위치**에서 울렸는지 알려준다.
   - 세대 화재면 "1204호 · 주방", 복도 화재면 "12층 복도" 처럼 표시.

3. **발생 층 세대 응답 수집**
   같은 층 세대들이 보낸 "우리 집 이상 없음 / 오작동" **보고 응답의 현황**을 모으는 항목.
   - 응답이 없을 수 있으므로 끝까지 완료되지 않고 "응답 대기"로 계속 로딩된다.
   - ⚠️ **이 항목은 화면 전환 트리거가 아니다** (아래 '전환 트리거' 참고).

4. **실제 화재 여부 교차 확인**
   **관리실**이 정보를 수집(감지기 다중 신호·대피 현황 등)해서 실제 화재인지 교차 확인하는 단계.
   가장 오래 걸리며, 이 확인이 끝나는 것이 전환의 마지막 트리거다.

## 화면 전환 트리거 (중요)
팝업 → 메인 화면 전환은 오직 **"실제 화재 여부 교차 확인"(관리실이 정보 수집해 교차 확인)** 이
끝나는 것만으로 일어난다. 이 하나가 트리거다.

- 나머지(감지기 신호 확인 · 발생 위치 특정)는 그 전에 빠르게 끝나는 진행 표시일 뿐이다.
- "발생 층 세대 응답 수집"(같은 층 세대의 보고)은 트리거가 아니다 — 응답이 없어도 계속
  "응답 대기"로 로딩만 돌고, 교차 확인이 끝나면 응답을 더 기다리지 않고 그대로 넘어간다.
- 코드: popup.js buildTimeline() — openTime = (교차 확인 완료 e3) + 360.

## 신고 버튼 권한 (오작동 / 우리 집 이상 없음 보고)
발화 위치(origin) × 보는 사람(scenario) 조합으로만 노출된다:
  - **세대 화재** → 그 세대(내 집)만
  - **복도 화재** → 같은 층 사람만 (내 집 · 같은 층)
  - **인접 층 / 먼 층** → 신고 버튼 없음
신고할 수 있는 사람은 본인이 곧 '발생 층 세대 응답'의 대상자이므로,
그들에게는 "발생 층 세대 응답 수집" 로딩 줄을 숨긴다.

## 시나리오 (TWEAKS.scenario)
- own  : 내 집 (발화 세대 / 복도면 발화 층)
- same : 같은 층 다른 호
- near : 인접 층
- far  : 먼 층 (자동 전환 없음 · 수동 진입 버튼)

## 발화 위치 (TWEAKS.origin)
- unit    : 세대 화재 — 발생 위치 "1204호 · 주방"
- hallway : 복도 화재 — 발생 위치 "12층 복도"

## Tweaks (인페이지 패널)
scenario · origin · lang(ko/en) · floor.  (tone, textSize 는 기본값 고정: 차분 톤 / 큰 글자)
패널은 호스트로 postMessage 한다. 단독 사용 시 popup.js 상단 TWEAKS 기본값만 바꾸면 된다.

## 타임라인 모델 (popup.js)
- buildTimeline(): 시나리오별 키프레임 { checkStart[], checkDone[], collectDone, openTime, Tend, noResp }
- renderAt(t): 순수 함수 — 시각 t(ms) 상태로 UI 전체를 세팅 (스크럽 가능)
- play / pause / seek / restart 가 currentT 를 움직이며 renderAt 호출

## 메인 화면
검은 배경 + "메인 화면" 플레이스홀더(#dash). 실제 대시보드는 #dash 내부만 교체하면 된다.
